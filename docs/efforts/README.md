# Efforts

Briefs for work outside a milestone's slices (jon-platform ADR-0005 D4), handed to the executor through
[NEXT_UP.md](../NEXT_UP.md). A brief is a dispatch document: the reasons live in the ADR it implements.

**The root holds only live briefs** (ADR-0005 D10). A live brief's header opens with `Status:` **Designed**,
**Ready**, **Dispatched** or **Blocked**, then a one-line `Summary:`. Finished briefs move to [archive/](archive/)
with `jon-platform/scripts/archive-brief`. **The table's row order is the queue** (D12).
